Aujourd'hui

Compteurs remis a zero chaque jour a minuit UTC. Les centiles portent sur les 200 dernieres requetes : ils disent ce que vit reellement un utilisateur, la ou une moyenne masque les cas lents.

Quatorze derniers jours

Recherches par jour, et part de celles qui n'ont rien rendu. Une part de vides qui grimpe est le premier signe qu'une source est tombee.

Service

Sources

Le rendement est le nombre de candidats rapportes PAR APPEL. C'est la seule mesure qui dise si une source sert a quelque chose : une source rapide qui ne rend jamais rien coute du budget a chaque recherche. Les mesures partent du dernier redemarrage.

Essai reel

Interroge la source pour de vrai, avec un titre de votre choix. La mesure passive ne dit rien tant que personne n'a cherche — c'est le seul moyen honnete de verifier qu'une source repond. Les sources a cle restent muettes ici : leurs cles appartiennent aux utilisateurs. Collez un segment de configuration pour les essayer avec.

Requetes recentes

Le detail par source de chaque recherche : duree et nombre de candidats rapportes. C'est l'outil de diagnostic — quand un utilisateur signale « je ne vois rien », la reponse est ici, pas dans les agregats.

Services externes

Joignabilite reelle, mesuree a la demande. Un refus d'authentification (401, 403) compte comme joignable : le service repond, il exige seulement une cle — le compter comme une panne enverrait chercher au mauvais endroit. Aucune cle d'utilisateur n'est employee ici : on teste l'adresse, pas les acces.

Domaines rotatifs

Les sites changent d'adresse ; la synchronisation les retrouve seule. Elle tourne automatiquement, ce bouton force un passage immediat.

Liens morts

Liens dont un debrideur a affirme que le fichier n'existe plus. Ils sont ecartes des resultats pendant un mois. Les oublier force un nouvel essai — utile quand un hebergeur remet un fichier en ligne.

Journal

Les 500 dernieres lignes. La sortie standard reste intacte : docker logs continue de tout recevoir, y compris ce qui aurait disparu d'ici.

Fan-out

Le budget est un plafond DUR : passe ce delai, les sources qui n'ont pas repondu sont abandonnees. Le baisser rend l'addon plus vif et perd des resultats lents ; le monter fait l'inverse, et AIOStreams coupe les addons trop lents.

Gouverne la reponse ENTIERE, enrichissements compris — la ou le budget de fan-out ne bornait que l'interrogation des sources. Ce qui n'a pas le temps de se faire est omis : une etiquette « pret » manquante vaut mieux qu'une reponse qui n'arrive pas.

Indexeurs

L'ADRESSE est a l'operateur, la CLE reste a l'utilisateur. Modifier une adresse ici suffit a suivre un tracker qui change de domaine, sans redeploiement.

Sauvegarde

Exporte les reglages d'operateur et les fichiers de configuration. Aucune cle d'utilisateur n'y figure : elles vivent dans leurs liens, pas ici. Ce fichier peut donc etre stocke sans precaution particuliere.

Cache

Purger un perimetre force sa re-interrogation. Utile apres un changement de cle ou quand une source a repondu vide a tort — un resultat vide est memorise, et il colle.

Fichiers de configuration

Edition a chaud : l'addon recharge sans redemarrer. Un JSON invalide est refuse AVANT ecriture — un fichier casse rendrait la source correspondante muette au prochain demarrage.
